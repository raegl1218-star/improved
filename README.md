# Gloria Food B2B Website

Static export website for Gloria Food, an IQF frozen food and Asian food OEM/ODM supplier.

## Local Preview

Serve this folder with any static server, for example:

```bash
python -m http.server 4173
```

Then open:

```text
http://127.0.0.1:4173/
```

## Key Pages

- `/`
- `/products/`
- `/iqf-frozen-vegetables/`
- `/oem-odm-private-label/`
- `/food-safety-certifications/`
- `/factory-quality-control/`
- `/blog/`
